# ATELIER — Contemporary Fashion

A luxury fashion ecommerce concept built with React, TypeScript, Vite, Tailwind CSS, Framer Motion, and Lucide React.

## Included

- Editorial ATELIER homepage
- 30-second video hero background at `public/atelier-hero.mp4`
- Collection, featured products, lookbook, new arrivals, studio story, press, and footer sections
- Product detail route with size selection and add-to-bag interaction
- Wishlist, search, account, cart, and newsletter UI interactions
- Responsive desktop and mobile layouts

## Run locally

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```
